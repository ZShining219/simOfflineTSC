Online–Offline 实验计划（按 training_seed 冻结版）

本计划仅讨论：

四个交通需求场景上的独立 Online DQN；
使用 Online DQN 轨迹进行纯 Offline DQN；
单个 DQN 按顺序经历多个场景时的在线训练；
场景切换时清空或保留经典 FIFO replay buffer 的差异。
一、全局随机性定义
1. training_seed

本计划中的 training_seed 专指：

run.py --seed

它控制：

Python random；
NumPy；
PyTorch CPU/CUDA；
DQN 网络初始化；
ε-greedy 探索动作；
replay buffer 随机采样；
训练过程中的其他算法随机性。

因此，它是一个智能体训练随机种子，不是 SUMO seed。

正式实验统一使用：

training_seed = [0, 1, 2, 3, 4]
2. SUMO seed

当前项目没有将 run.py --seed 传递给 SUMO。

因此本计划中：

SUMO seed mode = fixed default

即：

所有训练均使用 SUMO 当前默认随机实现；
不主动传递 --seed 给 SUMO；
不修改 route 文件；
不改变车辆数量、depart、route；
不将不同 training_seed 解释为不同 SUMO 微观仿真实现。

正式报告必须注明：

五次重复实验改变的是智能体侧训练随机性，SUMO 微观仿真随机性在当前工程中固定。

当前计划得到的方差表示：

DQN 初始化、探索和 replay 采样造成的训练方差。

不能表示：

不同 SUMO 微观驾驶随机实现下的性能方差。

3. 离线训练 seed

纯离线算法训练使用独立的：

offline_training_seed = [1000, 1001, 1002, 1003, 1004]

它控制：

离线 Q 网络初始化；
数据集 shuffle；
minibatch 抽样；
离线优化过程。

Online 数据中的原始 training_seed 应保留为：

behavior_training_seed

不能把五个行为数据 seed 当作五次离线训练重复。

1.5 经典 DQN replay 规则

每次独立运行只维护一个 replay buffer。

固定规则：

replay初始为空；
每个环境决策步产生一条 transition；
transition立即写入 replay；
episode结束时不清空 replay；
replay未满时持续增长；
replay达到容量后按 FIFO 覆盖最旧数据；
达到 learning_starts 后开始训练；
每次更新从 replay 当前内容中均匀随机采样；
不使用优先经验回放；
不按episode、场景或数据质量加权。
1.6 训练过程评估

1.7 模型报告规则

Checkpoint分为两类：

evaluation checkpoint保存online Q-network，并以该online Q-network执行评估；
resumable checkpoint保存online Q-network、target network、optimizer、epsilon、训练计数器、随机状态和恢复所需replay状态；
两类checkpoint必须记录schema/version，旧项目target-only模型文件不得被误标为新的evaluation checkpoint或resumable checkpoint。

主要结果使用：

episode 400 的最终 checkpoint。

同时保留：

训练过程中表现最好的 checkpoint。

但 best checkpoint只作为训练稳定性诊断，不作为唯一主结果，避免在固定仿真实现上选择性报告。

场景切换时：

4.4 Replay规则

整个700 episode运行始终维护同一个replay：

初始为空；
每步写入一条transition；
episode结束不清空；
场景切换不清空；
未满时继续增长；
满后按FIFO覆盖最旧数据；
每次更新从当前全部replay中均匀采样；
不按scene加权；
不设置新旧场景比例；
不设置额外阅读期；
不建立独立离线池；
scene_id只用于日志，不参与模型输入和采样。

如果切换时：

len(replay) >= learning_starts

则新场景第一条transition写入后即可继续执行常规DQN更新。

当前实验结论的统一边界为：

在固定单路口、固定交通需求文件和固定SUMO默认微观随机实现下，研究由不同智能体训练随机性产生的Online与Offline学习表现，以及经典DQN在交通需求场景顺序变化时的适应过程。

不能根据当前计划声称：

已验证不同SUMO seed下的鲁棒性；
五个training seed代表五个交通需求变体；
五个training seed代表五个独立微观交通实现；
已完成仿真到现实或随机交通需求泛化验证。
