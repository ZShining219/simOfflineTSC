## 改动意图

seq8 pilot（已关闭）在 `sequential/` runtime 下已有 CONT（纯在线）与
SELF-DHOA-R50（自产档案均匀重放）两臂完成数据：CONT 呈显著遗忘
（mean +21.4% / max +326%），DHOA 压平（mean +1.2%）。但 pilot 的锚定
臂（SELF-CQ）是数据层选池实现，属意图错误已作废——**「教师 ckpt 判决
进 loss」的真锚定从未在 seq8 序列上验证过**。本实验在 cl_hz1x1 链路
（仓内唯一激活半离线实现）上补跑带 policy anchor 的半离线臂，与既有
CONT/DHOA 数据合流，回答：「自产因果历史 + 教师锚定」在语义需求多样性
序列上能否进一步优于纯均匀重放。

## 实验设计

| 项 | 取值 |
|---|---|
| 臂 | `soddqnp_r25`：dqn + double_dqn + collect_history + causal + scene_intersection_balanced + **offline_ratio=0.25** + **anchor_lambda_policy=1.0**（T=1.0，λq=0 纯 policy KL） |
| 序列 | N1（无回访）/ R1（块重复回访）/ D1（渐变），scene_order 与 seq8 原序一致 |
| seeds | training {0,1}；stage 末 eval 格 sumo_seed=101（单种子固定） |
| 预算 | 100 ep/stage × 8 stage；steps=3600s；48 train-run + 216 stage 末 eval 格 = 264 task |
| 超参 | lr0.001 γ0.95 ε_decay0.995 ε_min0.01 batch64 buffer5000 target_update10 learning_start1000 interval10（与 seq8 协议一致，显式 overlay 覆写） |
| 教师 | 每场景 stage 末 resumable ckpt（episode_0100.pt）冻结注入 `teacher_paths`；R1 回访场景以最近一次 stage 末 ckpt 为教师 |
| 历史 | 每 stage 全量 `history_archive/` 落盘，stage k 可见 `scene_order[:k]` 全部归档 |
| 评估 | ① 训练 run 内 `evaluation_episodes=0..100` 逐 ep 当前场景（波动曲线）② stage 末 eval 格对已见 1..k 场景（下三角矩阵） |
| 入口 | `python3 dev/seq8_anchor/build_queue.py formal` → `tools/run_experiment_queue.py --queue artifacts/seq8_anchor/run_queue_seq8_formal.json` |
| run 前缀 | 冒烟 `s8q_` / 正式 `s8f_`——首次正式派发误用冒烟前缀致 runner 将 5ep 冒烟产物误判完成（st2 起级联 FAILED），已换前缀重建并重新登记台账 |

**基线与对比口径（已知 caveat）**：CONT/DHOA-R50 基线取自 `sequential/`
runtime 已完成 run（6+6），本批在 `run.py`+queue 链路——跨 runtime 对比
存在训练循环/rng/回放结构实现差异，结论引用时需标注。

**冒烟结论**（N1×sd0×4stage×5ep，14/14 SUCCEEDED）：需求包场景正常载入；
`history_archive` 每 stage 落盘（1800 trans/5ep）；`anchor_policy_loss`
非零（1.0→5.2 随 update 变化）；`offline_count=16`（64×0.25 正确）；
stage 链 `depends_on`/`requires` 门控正常；stage 末 eval 格正常产出。
