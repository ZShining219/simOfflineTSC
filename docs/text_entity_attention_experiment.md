## 1. 研究问题与证据边界

研究问题：在公开报告到交通实体的对应关系可靠时，智能体能否学习结合事件文本与实时车道状态，改善事件条件下的交通控制，并协调相邻路口。

分开检验三个假设：

| 假设 | 需要的证据 | 不能作为替代的证据 |
| --- | --- | --- |
| H1：输入链路正确且参与优化 | 报告/实体/特征/时刻对应正确，融合参数收到 RL 梯度，checkpoint 可重放 | 仅模块存在、输出形状正确 |
| H2：模型对文本内容和对应实体有选择性响应 | 同一状态下分别干预语义和映射，检查 Q 值/动作及局部响应；合法同义表达作后续专项 | 仅注意力热图、掩码命中率或动作变化率 |
| H3：正确文本及实体注意力改善控制 | 与匹配基线、语义/映射反事实的多种子配对效果 | H1/H2 成功、单例变好、事件使交通变差 |

已有 TARL V2.1 负结果仍有效，见 [最终报告](../reproduction/tarl_tsc/reports/FINAL_REPRODUCTION_REPORT.md)。新研究使用新事件模块、新模型身份和新输出目录；历史模型或指标不与新结果直接合并。正常/事件分布、物理机制和文本时序均发生变化，所有正式基线需在同一新协议下重训。

参考 [EMMA / ICML 2021](https://proceedings.mlr.press/v139/hanjie21a.html) 的实体条件描述注意力：实体查询多条文本描述，融合后进入策略。文本映射参考 [BLINK](https://aclanthology.org/2020.emnlp-main.519/) 和 [PURE](https://arxiv.org/abs/2010.12812) 的抽取/链接分工；当前采用规则，不宣称复现其神经抽取器。新模型称为实体条件文本注意力 DQN 的项目实现，不冒称原作者交通模型。

## 2. 冻结和开放的部分

- 固定规则映射 v1、六种公开模板与静态 catalog 的输入边界。学习型抽取列为后续独立实验，不在本阶段同时更换。
- 固定外部事件物理算子；日程的抽样、规模和训练分布可以在 pilot 阶段设计，但须在正式实验前固定。
- 新增逐报告文本编码、车道实体表示、融合模型和 replay 数据路径。当前 `TARLPolicy` 的整路口向量/two-token 融合不能直接等同于新模型。
- 当前目标是在可训练论文基线下检验事件扰动学习与泛化，并在统一 DQN 骨干下验证文本融合机制。纳入 PressLight、FRAP、CoLight 项目实现；离线/半离线训练及额外 PPO 系列暂不进入首轮，避免进一步扩大范围。
- 文本只来自公开快照；不读取 schedule/audit 中的真实目标、剩余时长或未来事件。策略可访问静态路网、当前交通状态和公开更新时间；首轮不额外编码更新时间，避免输入项扩张。

## 3. 数据与模型接口

每个决策时刻保存一个完整路网样本，张量约定：

| 输入 | 形状 | 来源 |
| --- | --- | --- |
| 车道计数 | `[B,N,L,1]` | 原始进口 lane_count，使用 binder 的真实顺序与 padding mask |
| 相位 | `[B,N,A]` | 当前相位 one-hot，各对照相同 |
| 车道静态描述 | `[N,L,D_static]` | catalog 的行驶方向、转向等；所有方法共享同样信息 |
| 报告表示 | `[B,R,768]` | 每条报告单独冻结 BERT 编码、masked mean pooling；不将全网报告先拼成一句 |
| 报告有效位 | `[B,R]` | batch padding；与空报告、解除报告区分 |
| 实体对应 | `[B,N,L,R]` | v1 `feature_report_mask`；含对应关系而非真实物理目标旁路 |
| 图邻接关系 | `[N,N]` | 静态路网，由显式节点顺序构造，包含 self-loop |

`B` 为 replay batch，`N` 为路口，`L` 为补齐后的进口车道数，`R` 为该 batch 最大报告数。lane_count 不可直接视为任意交通流向的独立计数：共用车道不复制成独立的左转/直行需求。

编码器复用已有完整冻结 BERT 资产与缓存思路。新调用层处理空报告和批次 padding，不修改冻结的历史 encoder 文件。每条原始报告及字符映射保留用于审计；送入 BERT 前统一去掉 `Event <id>.` 前缀，避免事件编号成为事件类型/位置的捷径。实体 ID 仍可出现在公开语义中，不能宣称实现陌生自然语言实体识别。所有文本对照采用同一预处理；不静默截断报告，记录 token 长度，超限在输入校验阶段拒绝。

### 3.1 实体条件跨模态注意力

使用共享车道编码器，将当前车道计数、该路口相位及静态描述编码为 `h[n,l]`；文本编码投影为报告 `e[r]`。建议初始隐藏维度 64、4 个头，与现有模型规模接近，pilot 后统一固定。

```text
公开报告 → 规则映射 → M[n,l,r]
    └──→ 逐报告冻结 BERT → e[r] → K,V
车道状态及静态描述 → h[n,l] → Q
Q,K,V + 实体关联偏置 → 文本上下文 c[n,l]
残差融合 h+c → 路口内车道自注意力与掩码池化
路口图自注意力 → 每路口 Q(s,text,a)
```

首轮推荐软关联偏置：`score[n,l,r] = QK^T/sqrt(d_head) + log(2)*M[n,l,r]`；关联项固定为同一常数，Q/K/V 从 TD 损失训练。无映射对照将关联项置零。矩阵来源必须是文本解析结果。

所有行增加一个“无须使用文本”的 null key，null value 固定为零。padding 报告严格屏蔽；R=0 时文本上下文直接为零。这样单条报告也能与 null 比较，状态可以学习忽略文本。不能对唯一报告做硬掩码 softmax 后把恒等于 1 的权重解释为学会关注；全 mask 行也不得产生 NaN。

残差保留交通状态；模型不因没有报告或报告无直接对应而失去控制能力。路口内车道 self-attention 和路口间图 self-attention 在所有方法中一致；各自的注意力与文本 cross-attention 分开记录，不能混淆。

封路可能主要影响上游路口，而直接目标车道属于下游进口。首轮保留所有报告的可访问性，用软偏置及同一步的邻居图传播传递信息；不用直接目标掩码硬禁止上游访问。可记录道路 `from/to` 关系用于解释，但首轮不新增未经对照的“真值上游影响标签”。边界出口或内部车道没有绑定特征时，保留报告及无观测实体清单，报告仍可被软注意力访问。

### 3.2 生命周期、replay 与优化

- 每个事件只保留最新公开报告；cleared 同样进入文本分支，v1 不删除它。本轮每回合事件数有显式上限，防止报告无限积累；不使用未来 end 决定可见性。
- replay 同时保存 s/text/mask 和 s'/text'/mask'、动作、区间 reward、终止/截断语义及布局/编码器版本。旧样本绝不重新查询当前 runtime。
- BERT 冻结特征允许缓存；训练中的投影、Q/K/V、融合及 self-attention 不缓存为固定特征。
- 保存在线/目标网络、优化器、随机数状态、采样位置和所有输入协议身份；重放检查跨路口、跨样本无错混。
- 遵循现有合法相位/黄灯行为。固定决策间隔先取 10 秒，SUMO 物理步长 1 秒，区间内事件逐秒执行、下个决策读当前报告。公开更新时间是实际生效时刻，不意味着控制器每秒行动。
- 对终止和 horizon 截断分别明确 TD 是否 bootstrap，统一用于全部方法；实现前核对现有 trainer 行为后在配置中固定，不沿用不明默认。

## 4. 主对照：六种同骨干方法

本节是解释融合机制的内部对照。六种方法用相同车道编码、车道/路口 self-attention、动作、奖励、经验容量、训练步数及事件计划；只改变指定融合分支。论文方法的外部效果对照另见 4.1，不能要求它们全部换成本文骨干后仍宣称复现原方法。

| 方法 | 文本输入 | 实体对应 | 融合方式 | 用途 |
| --- | --- | --- | --- | --- |
| S：Sensor | 无 | 无 | 仅状态路径 | 判断整套附加信息的收益 |
| U-Mean | 完整报告向量 | 无 | 固定均匀加权，再用公共残差融合层 | 广播文本基本对照 |
| M-Mean | 完整报告向量 | 有 | 固定权重 `softmax(log(2)*M)`，再用公共残差融合层 | 映射但不学习文本注意力 |
| U-Attn | 完整报告向量 | 无 | Q/K/V 跨模态注意力 | 无映射的注意力对照 |
| M-Attn | 完整报告向量 | 有 | Q/K/V + 相同实体偏置 | 主方法 |
| M-Constant | 每条报告相同的常量向量 | 有 | 与 M-Attn 相同 | 检查映射位置、报告数量和出现时序是否已解释收益 |

Mean 方法也包含零值 null 项、同一报告有效位和输入规范；其权重固定，与状态无关。Mean 与 Attn 使用相同的可训练 value 投影、输出投影、残差与后续 FFN/归一化，避免把 concat 与 residual 的差异混入“注意力收益”。Constant 不接收事件类型、active/cleared 类别或报告更新时间，但保留相同报告槽位和实体映射，明确它是“只有映射与存在性”的控制组。

核心比较：M-Attn vs M-Mean（学习注意力）、M-Attn vs U-Attn（映射）、M-Attn vs M-Constant（超出实体位置/存在性的文本内容）、M-Attn vs S（总效果）。给出参数量和推理/编码成本；融合支路尽量匹配参数预算，匹配策略在 pilot 前记录，不能把结构容量增益直接称为注意力收益。

已有 TARL Attention/Gating 可以列为历史结构参考，但若放入性能表，必须在新事件协议上重训并说明骨干差异。MaxPressure 和经过实际相位轨迹核验的 FixedTime 可作辅助基线，不承担上述因果拆分。当前事件验证入口的 FixedTimeAgent 有已知逐秒切换问题，未经修正验证不能作为标准 fixed-time 对照。

| 方法 | 论文与关注机制 | 仓库实现 | 本轮核查状态与进入条件 |
| --- | --- | --- | --- |

这三项论文方法是当前仓库的项目实现。FRAP/CoLight 已完成上述范围的工程验证，PressLight 的本轮验证及三者完整论文一致性审计仍待完成。进入正式表前记录论文差异、代码版本、状态/奖励、参数共享方式和必要适配；正确性修复先通过单独验证，不能为提高相对排名改变方法定义。旧 FRAP/CoLight 与 trainer 文件属于历史冻结清单，本轮没有修改它们；验证通过标准 trainer 检查点接口，不能推广为旧版 agent.load_model/save_model 的全部分支都正确。

外部论文比较保持同一路网、车流、事件计划、合法动作、决策间隔、交互预算、评估集与调参资源。优先保留各方法原有核心状态/奖励设计，使用统一外部指标评估。各方法实际可见的交通观测、更新次数、样本复用率、模型容量和耗时逐项披露，不把异构方法效果差直接归因于文本注意力。若统一奖励/状态，则明确另标“统一协议适配版”，与原方法配置分开。

PressLight 等能观察下游状态的控制器可能已从传感器推断封路；这属于有效强基线，不能人为删掉其信息以制造文本收益。同骨干的六组对照才用于拆分映射和语义的贡献。

### 4.2 两种训练分布：学过扰动与未学过扰动

对 S、PressLight、FRAP、CoLight 各自训练两套独立模型，使用相同交互预算与训练种子：

- **N-train**：仅正常交通训练；评估正常交通和各事件测试集，测量部署扰动造成的性能变化。
- **E-train**：正常交通与多样事件混合训练；训练过程中真实施加事件、收集受影响的状态/奖励并更新网络。基线不接收报告、实体掩码、事件类型、事件日程或真实目标。

主比较对象是已经接受 E-train 的论文方法。文本模型及其余五个同骨干变体同样采用 E-train，不以“本文模型训练时见过事件、基线只见过正常交通”构造优势。

N-train 与 E-train 在同一个事件实例上的差值衡量扰动训练的效果；各自 Event−Normal 差值衡量事件损失；E-train 在同分布与分布外测试上的变化衡量泛化。同时报告正常交通性能，检查鲁棒性是否以日常效率为代价。

测试均固定 checkpoint、关闭探索且禁止梯度更新。根据当前观测改变动作属于策略响应，不称为测试期继续学习。后续若研究在线适应，应另设更新预算、样本可见性和新结果身份。

## 5. 干预与机制验证

同时做静态状态探针和独立闭环评估。前者固定同一 checkpoint 与同一交通状态，仅改变文本/映射；后者保持事件物理、需求、种子和 checkpoint 相同，允许动作变化导致状态轨迹不同。不得声称闭环轨迹始终相同。

| 干预 | 固定什么、改变什么 | 解释 |
| --- | --- | --- |
| 整体无报告 | 去除文本槽位与关联矩阵 | 总信息消融，不能单独归因于文本语义 |
| 固定映射、常量文本 | 固定槽位和 M，只替换编码器输出 | 语义通道消融；属于解析后的诊断，不伪称解析空字符串 |
| 固定文本、打乱映射 | 同一 e 和报告槽位，按固定排列置换局部关联；全局降雨不参与无效置换 | 映射依赖；属于模型内部诊断 |
| 合法错误位置报告 | 同时重写 lane/edge/junction/方向/转向使之自洽，再正常解析 | 完整公开输入链路反事实；错误文本和 M 同时变化 |
| 合法错误状态报告 | active/cleared 同步修改文本与公开 status，更新时间保持同一可用时刻 | 检查是否利用解除语义；物理事件不变 |
| 报告 ID 重命名/报告顺序重排 | 语义和关联列同步保持一致 | 编号不应改变编码后输入；列置换应在容差内保持 Q 值 |

错误位置从静态目录选择真实、几何上可用的替代目标；不能只改一个 ID 触发解析异常后把空映射退化当作模型响应。错误类型通常改变作用范围和字段，不列为首轮纯语义主对比。wrong-status 的数值字段不对称须记录，不声称仅替换一个词。

机制记录包括分头报告/null 权重、Q 差异、动作概率或 argmax、文本分支梯度范数、各车道上下文范数。Q 变化不要求每个状态都导致动作翻转；梯度检查使用非对称输入与多报告样例，避免 softmax 退化。证明样本间无 attention 串线，空文本仅走状态路径，动作均合法，target 网络不参与优化。

模型注意力集中于正确实体本身不作为成功条件，因为 M 已给出位置偏置。必须结合内容消融、固定映射对照和闭环指标判断。

## 6. 场景、pilot 与正式预算

先用 hz4x4、新事件模块和 SUMO 1.27.1 建立可复现实验。已知局部阻塞配置对总体流量影响较弱，不能直接把工程验证日程当作有辨别力的正式实验。

阶段建议如下；以下数字是设计候选，尚未成为冻结配置：

1. **P0 工程验证**：重用 v1 测试；用三类事件及解除的短回合走通推理、replay、TD 更新、checkpoint 重放。额外构造单报告、多报告、全无关联和全 padding 测试。
2. **P1 可控性与 pilot**：开发种子 101、103；先用 S 与显式结构化事件诊断模型检查“附加事件信息是否存在可控制收益”。结构化输入只用公开报告可解析字段，与 M-Attn 可得信息相同，不注入隐藏未来；其失败不能证明收益不可能，只用于排查奖励/状态/场景。同时完成三种论文方法的 N-train/E-train 小预算训练和不同扰动测试，核查相位、图索引与优化过程，再以六种同骨干方法确定融合资源和预算。
3. **P2 冻结正式协议**：保存事件计划、训练/验证/测试拆分、种子、参数、指标、checkpoint 规则和源码/资产哈希；冻结后不依据测试收益调整事件强度或预算。
4. **P3 正式实验**：训练种子候选为 7、17、27、37、47。先做 S 与三种论文方法 × N/E 两种训练分布 × 5 种子，共 40 次；再做其余五种同骨干文本变体 × E-train × 5 种子，共 25 次。S/E 的 5 次只计一次，总计 **65 次独立训练**，替代早期仅六种融合方法的 30-run 方案。每次候选 300 回合、3600 秒/回合、10 秒决策；预算是否充分由 pilot 的共同准则决定，在 P2 前统一调整。相同 checkpoint 评估多个测试组无需重训；结构化诊断模型若进入正式比较需另计预算。当前尚未生成正式配置或启动这些运行。

训练日程建议 30% Normal、40% Single（三类型平衡）、30% Multi（两事件）；在每个方法/种子内复用同一预生成计划。每回合最多两个事件，均在 horizon 前解除，并留下至少 600 秒恢复区间。候选开始时间 600–1800 秒、持续时间 180–600 秒；目标从固定有效集合抽样。Multi 同时包含分离目标和同一局部区域的重叠情况，单独标注组合。

训练/验证/测试按事件实例与以下分组规则分离，分别管理训练随机数、SUMO 需求种子和事件计划种子。同分布测试候选为 Normal 加每类 10 个 Single、10 个 Multi 固定场景，各配 3 个未用于训练的需求种子；位置、参数和组合外推使用规模相当的分层测试组，在 pilot 后记录实际任务数与评估成本。测试种子、目标集合及所有边界在 P2 明确列入配置，当前不声称已生成。

### 6.1 “不完全一致的扰动”分层验证

物理扰动变化是本轮主轴，公开报告保持规则 v1 可解析且如实描述当下情况；文本错报/漏报是第 5 节单独的消融。不能混为一个“扰动泛化”指标。

| 测试组 | 相对 E-train 改变什么 | 保持什么 | 可以支持的结论 |
| --- | --- | --- | --- |
| T0 Normal | 无事件 | 相同网络与需求分布 | 常态控制性能及鲁棒训练代价 |
| T1 新实例，同分布 | 重新采样合法日程、需求种子；事件实例不与训练重复 | 类型、目标候选集合、参数支持范围和组合规则 | 排除固定日程记忆，检验分布内泛化 |
| T2 未见受扰位置 | 使用训练时未施加该类事件的 lane/edge 组 | 类型、强度、时长与需求分布 | 同一路网中的事件位置迁移，不是新路网泛化 |
| T3 参数外推 | 分别改变持续时长或可调物理强度到训练支持范围外 | 目标来自训练集合，其余因素固定或配对 | 参数外推；单列强度与时长，避免多因素混杂 |
| T4 未见事件组合 | 使用训练中未出现的事件类型配对或空间/时间重叠模式 | 单个事件类型和参数范围已经见过 | 已见基本事件的组合泛化 |
| T5 联合变化 | 未见位置加未见组合/强度；必要时再加需求变化 | 所有方法面对完全同一测试集合 | 综合压力测试，不能据此单独归因某一变化 |

T0–T4 是正式核心测试，T5 为预先指定的补充压力测试。先分析单因素，再分析联合变化。全局雨不适用 T2 局部位置测试；道路封闭在当前执行器中是二值权限，不存在可直接调节的“封路强度”参数。不能为了生成强度外推而偷偷引入第四类物理机制。

### 6.2 扰动参数、拆分与防止记忆

- **位置拆分**：将外部有向 edge 分为训练、验证和测试目标组；同一 edge 的多条 lane 不跨组冒充未见位置。必要时将同一路口邻接道路整体成组，并在 P2 固定拆分单位。位置外推中路网实体可在正常观测和静态 catalog 中出现，只是没有在训练中作为受扰目标。
- **时长外推示例**：训练持续 180–360 秒，测试持续 420–600 秒，其余因素配对；开始时刻独立抽样并满足解除后至少 600 秒。该示例在 pilot 可控性检查后才能冻结，不与前述更宽的候选采样范围同时作为最终配置。
- **雨强外推示例**：训练 `speed_factor` 为 0.70–0.90，测试为 0.50–0.65；数值越小限速越强。这只是当前代理机制下的外推，不代表真实雨量等级泛化。
- **局部阻塞**：位置与距停止线距离可变化，但须按真实车道长度和安全放置要求检查；将其单列几何位置变化，不把障碍位置或多事件数量无条件等同于强度。道路封闭只在目标、起止时间和组合维度变化。
- **组合留出示例**：训练允许阻塞+降雨、封路+降雨，保留阻塞+封路用于 T4；单独的阻塞、封路都必须在训练中出现。另可固定类型配对而只留出空间邻接/时间重叠模式，作为独立子组，不与类型组合效应混算。
- **采样身份**：在 P2 固定每回合 `(事件类型,目标,参数,begin,end,需求种子)` 的计划与哈希；仅更换事件 ID 不算新实例。同分布组查精确重复，外推组另查目标组、区间与组合支持集合是否真正互斥。
- **验证集职责**：调参、预算、checkpoint 选择只使用开发/验证集合，不依据最终留出的目标、强度或组合效果调整方法。不同类型使用平衡或预先规定权重；所有方法共享同一计划与权重。
- **事件学习可追踪性**：记录实际执行成功的事件、公开报告时间及基线 replay 中的同期状态/奖励，仅验证端保存目标标签。基线训练确实经历扰动才称为 E-train，不能只改变测试环境或生成未被执行的配置。

本轮不将“完全未见过的事件类型”纳入主结论。该问题需要 leave-one-type-out 的独立训练协议，文本模型也不得在训练数据或辅助监督中接触该类型；可在核心实验完成后扩展。原模板下的物理扰动泛化不等于自由文本泛化。

事件选择须同时确认：物理作用成立、交通指标有可测影响、信号控制有调整余地、报告含超出当前 lane_count 的信息。严重封路或全网降速造成损失，并不自动意味着调整信号可以消除损失。先解决此问题，再投入全部正式训练预算。

## 7. 指标与统计

首轮主指标建议为：固定 3600 秒窗口内普通车辆的全网平均排队数（逐秒停止车辆数，统计一次，不重复计入相邻路口），越低越好。定义在执行前与日志实现核对，并对各事件类型分别报告，不能只汇总有利场景。

同时记录完成车辆行程时间、吞吐量、累计等待、车辆时间积分、待插入需求时间、未完成/未插入车辆、碰撞与 teleport。普通车辆排除人工障碍。到达车辆的均值存在截尾偏差，不单独作为收益依据；排队下降同时吞吐量下降也不能直接称为改善。SUMO time-to-teleport、路线选项及无事件空日程在所有方法中相同。

局部指标：目标车道、封路起点路口进口、邻居路口分别统计排队/等待/服务分配；全局雨使用全网范围。局部指标区域可由验证端真值定义，但不传给策略。按事件前、物理作用、解除后 600 秒分别报告；报告状态区间 `[begin,end)` 与一步交通样本 `(begin,end]` 的约定保持一致。

先在每个训练种子内，对相同需求与场景求配对差，再在训练种子层报告均值、全部五个种子的差值与 95% 配对置信区间；不能把逐秒数据当独立样本扩大样本量。样本量小应说明区间不稳定。内部四个方法对比、三项论文方法对比及 N/E 训练差异分别预先登记检验族，对 T1–T4 的多次比较明确校正范围，使用 Holm 校正的配对检验作辅助证据；实际意义阈值在 P2 前写定，测试后不追加阈值。场景细分和注意力图为诊断结果，区分探索性分析。

额外输出“方法 × N/E 训练 × T0–T4 测试”的性能矩阵及事件前/中/后的配对差值曲线。曲线围绕发生和解除对齐；不同时长分别分层或采用清楚标注的相对时间窗口。OOD 效果始终在相同 OOD 场景上横向比较各方法。更强物理扰动本身会增加难度，因此 OOD−ID 的原始性能差不能全部解释成泛化失败；辅以各策略在配对无事件场景下的事件损失，以及主方法相对基线的差异。

结果判定：

- H1 通过仅说明工程链路成立。
- H2 通过说明模型使用了输入，尚不说明使用正确或有收益。
- M-Attn 相对 S 改善，仍需 M-Mean/U-Attn/M-Constant 对比才能归因。
- 若 M-Constant 与 M-Attn 接近，则目前证据主要支持位置/存在性信息，而非文本内容。
- 若 M-Mean 与 M-Attn 接近，则不能声称学习注意力优于固定融合。
- 正式结果不稳定或置信区间跨零，报告未建立稳定优势；不把未显著解释为等效。
